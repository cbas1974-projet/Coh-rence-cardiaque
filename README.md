# 🫀 Cohérence Cardiaque

Une application web moderne et addictive pour pratiquer la cohérence cardiaque avec des mantras inspirants sur la ténacité.

![Application de Cohérence Cardiaque](https://img.shields.io/badge/Status-Ready-success)
![Version](https://img.shields.io/badge/Version-1.0.0-blue)

## ✨ Fonctionnalités

### 🎯 Respiration Guidée
- **Animation visuelle hypnotique** : Un cercle qui pulse en suivant votre rythme respiratoire
- **Guidage vocal textuel** : Instructions claires "Inspirez..." / "Expirez..."
- **Timing personnalisable** : Ajustez les durées d'inspiration et d'expiration selon vos besoins

### 💪 Mantras Inspirants
- **20 mantras sur la ténacité** qui changent dynamiquement pendant votre session
- Messages motivants pour cultiver votre persévérance et détermination
- Rotation automatique tous les 3 cycles de respiration

### ⚙️ Paramètres Personnalisables
- **Durée d'inspiration** : 2 à 10 secondes (défaut : 5s)
- **Durée d'expiration** : 2 à 10 secondes (défaut : 5s)
- **Durée de session** : 1 à 30 minutes (défaut : 5 min)
- Paramètres sauvegardés automatiquement

### 🎮 Système Addictif
- **🔥 Streaks** : Nombre de jours consécutifs de pratique
- **✨ Compteur de sessions** : Suivez votre progression
- **⏱️ Temps total** : Visualisez le temps total de pratique
- **🏆 Achievements** : Débloquez des messages spéciaux à 7, 30 jours, 10, 50, 100 sessions
- **📊 Statistiques persistantes** : Vos données sont sauvegardées localement

### 🎨 Design Moderne
- Interface épurée avec dégradés violets inspirants
- Animations fluides et satisfaisantes
- Effets visuels de célébration à la fin des sessions
- Design responsive (mobile et desktop)
- Effets de glassmorphisme

## 🚀 Utilisation

### Installation
1. Clonez ce dépôt ou téléchargez les fichiers
2. Ouvrez simplement `index.html` dans votre navigateur
3. Aucune installation ni serveur requis !

### Première Session
1. Cliquez sur "Commencer" pour lancer votre première session
2. Suivez le cercle : il grandit quand vous inspirez, rétrécit quand vous expirez
3. Lisez les mantras qui apparaissent pour renforcer votre mental
4. Complétez la session pour commencer votre streak !

### Personnalisation
1. Cliquez sur l'icône ⚙️ en haut à droite
2. Ajustez les durées selon votre confort :
   - **Débutant** : 4s inspiration / 6s expiration
   - **Classique** : 5s inspiration / 5s expiration (cohérence 365)
   - **Avancé** : 6s inspiration / 6s expiration
3. Choisissez la durée de votre session (recommandé : 5 minutes, 3x par jour)

### Contrôles
- **Commencer** : Lance une nouvelle session
- **Pause** : Met en pause / Reprend la session
- **Arrêter** : Arrête la session en cours

## 🧘 Bienfaits de la Cohérence Cardiaque

La pratique régulière de la cohérence cardiaque apporte de nombreux bienfaits :

- 😌 Réduction du stress et de l'anxiété
- 💤 Amélioration de la qualité du sommeil
- 🧠 Meilleure concentration et clarté mentale
- ❤️ Régulation du rythme cardiaque
- 🛡️ Renforcement du système immunitaire
- 😊 Amélioration de l'humeur

**Protocole recommandé** : 3 sessions de 5 minutes par jour (matin, midi, soir)
